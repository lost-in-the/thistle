## Reading presentation

`SourceComprehensionPresenter` renders Rust's projection and already admitted
Reader.source responses. It makes no Reader calls and derives no relationships.
It reuses the existing `.cvwrap`, `.cv.codeview`, `.source-row`, `.ln`, `.src`,
`.selected` and token classes, with the existing highlighter injected. Source is
rendered before the expandable provenance/coverage detail; the short method
outline is ordinary keyboard-operable HTML. Schema/callback context is composed
by the shared View after source. No custom renderer framework or JavaScript.

This uses the Field Guide structure already adapted in
[REUSE.md](REUSE.md): Woods Map revision
`29e7f6ac60bdeb8eee50138c2c87bd7ae21442a9`, source-view blob
`add843e1a18d88c7109262c30e19b7ed8ac79f92`, highlighter blob
`3768fc52d9932afd9a199c03d232b4a3a12a9a93`, token stylesheet blob
`28876d6fb3455381bb8c961e9e25654f77bb8451`. Copyright Leah Armstrong;
[upstream MIT notice](../LICENSE.woods-map.txt). This change adds an independent
Thistle presentation adapter over those existing patterns, not a Woods engine.

`navigation:` must implement the settled shared `url(path, extra_hash={})` API.
Source witnesses call `/source`, `{id: saved_id}`, then `#Lphysical_line` where
available. Caller witnesses call `/links`, `{id: saved_id, direction: incoming}`.
The authority attaches generation/search/investigation. The presenter does not
copy query keys or reconstruct URLs. An optional `continuation_url:` adapter maps
the Core's typed selector through a Root-admitted family route. Without it, the
presenter states that continuation is unavailable instead of inventing a route.

Each code block keeps original file bytes and physical line numbers. Local anchors
include the source fact ID to avoid line collisions across contributions. Missing
source remains a notice and exact Source follow-up. A descriptor without a saved
definition remains missing; a lexical incoming reference is not a verified caller.

The presenter admits at most 64 KiB aggregate source bytes, 2000 lines per file,
16 contribution rows, and 768 KiB body bytes. It verifies source generation, fact
ID/path/span and SHA-256 before highlighting. It conservatively charges duplicate
responses and renders a file once. Root must reserve/admit source and HTML envelope
cost before fetching, and account for highlighter expansion and escaped repeated
URLs. These are display guards, not latency/RSS evidence. Display refusal keeps
the Reader continuation/Source path; it must not imply missing evidence.

## UNRUN installed and served acceptance protocol

Root supplies a settled reviewed source SHA, built-once Core/Map package hashes,
loaded native identity, lock/cohort identities and an actual finite process/disk/
output/resource lease. Do not use a checkout-native library as installed evidence.
Use new task-local source/store paths; preserve the retained host/data/credentials.
No source-only worker may execute the following protocol.

1. Copy the dedicated fixture into a new controlled source directory. The
   `source_comprehension_installed_journey.rb produce` mode boots genuine Rails,
   loads the model/concerns and captures A through the installed gem. It then
   replaces only that disposable source with B and advances CURRENT. Keep A.
   This producer supplies `{models: [Los147::Order], stop_before: ActiveRecord::Base}`
   explicitly; normal captures do not discover classes for this optional family.
2. Start a separate consumer process with the installed Core/Map gems, outside
   their checkout/load paths and without Rails/ActiveRecord loaded. Its consume
   mode opens A explicitly, walks both bounded families, checks physical source
   and ambiguity against the fixture, then closes its Reader. CURRENT must be B.
3. Root wires the actual admitted route adapter and starts one authorized Map
   instance pinned by the ordinary generation-bearing authority. Serve through
   existing access/Host/HEAD/CSP controls, without adding a public endpoint or
   new credentials. Open the model from Find with a literal search/filter and an
   investigation selection. Record all actual artifact/fixture/generation IDs.
4. An investigator who did not implement this slice receives the questions below,
   not a click script. Their answer card is checked independently against exact
   fixture source and separately recorded observations. Follow concern/override
   and caller to exact Source. Return with search/filter/selection/generation
   intact; reopen the focus URL after CURRENT B is published.
5. Repeat affected navigation at 390px width and keyboard/no-JS. Check visible
   focus, literal Find/Source/Links/Check labels, keyboard scroll region and long
   source overflow. Agent operation does not establish person/IME/assistive-tech
   acceptance; record those separately as UNRUN unless actually performed.
6. Retain actual screenshots: model as-written source, concern/prepend contribution,
   duplicate alternatives, missing source, exact caller line, return context and
   390px reading. Include before/after for any observed reading correction.
   An HTML mock or HTTP200 is not this visual deliverable. Stop the compute and
   release the execution/UI claims through the existing host lifecycle.

The opt-in installed harness deliberately fails if shared Reader wiring is absent;
it has no simulated-data fallback. Its pure presenter tests use a recording
navigation double only and are labelled accordingly. Served/access/screenshots
remain separate from that producer/consumer check.
