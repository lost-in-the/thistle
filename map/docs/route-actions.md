# Follow a recorded route to saved action candidates

From a route's Source or Links evidence, choose **Inspect controller/action
candidates**. The read-only `/route-actions` page asks Native once for the saved
route's conventional static candidates. It displays original defaults,
constraints/provenance, qualified counts, missing/unsupported/partial states and
an explicit continuation. It never claims dispatch or executes route conditions.

Choose **Open exact saved Source at line …** to open a candidate's original
captured file with its selected declaration and `#L` anchor. No physical mapping
means an explicit reason rather than a fabricated link. Source verifies the
selected generation's bytes; CURRENT and live files do not replace the answer.
The route itself has no invented physical position.

The shared NavigationContext owns every URL. Generation, search and all collected
IDs are retained; the existing 4096-byte/nine-field limits and explicit search
omission notice remain. The presenter has only injected navigation and the
typed response, with no Reader, custom URL builder, inferred target or fallback
lookup. A page uses at most eight candidates, reduced for link display admission,
32 KiB Reader response and the existing total page limits. Exact destinations
accept generation, ID, selection, cursor and bounded search fields. Invalid
fields or a cursor for another route/generation are refused before Reader opens.
Existing host/peer authorization, CSP and GET/HEAD boundaries apply.

See the [Core contract](../../docs/development/route-actions.md) for the bounded
naming convention, DTO, costs and unknowns. The source journey is implemented;
native, installed, actual served/browser and person acceptance remain pending.
The authored installed contract follows the rendered physical Source link after
CURRENT advances, but has **not run** in this source-only task. Root owns those
admissions, independent review and integration. This does not complete broader
Passage, qualify L02/L07/L14/L15 or any of the 17 launch capabilities.
