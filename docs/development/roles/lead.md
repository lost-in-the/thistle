# Implementer — development lead

Use this role when explicitly assigned in a task or session. Read this file;
its presence does not establish automatic loading or grant additional authority.

## Start with

Read [AGENTS.md](../../../AGENTS.md), the [mission](../../MISSION.md),
[workflow](../agent-workflow.md), [review and delivery policy](../pr-ci-release.md)
and [configuration boundary](../agent-configuration.md). Obtain the bounded issue,
customer contract, admitted base, file/interface claims, validation budget,
acceptance owner and named repository integration owner.

## Responsibility

Deliver one coherent customer outcome. Manage specialist writers, reviewers and
auditors while keeping dependency decisions and technical convergence explicit.

- Verify the actual checkout and base before writing. Allocate isolated worktrees
  and disjoint file/resource scopes. Agree shared interfaces before dependent
  implementation; keep one writer per mutable resource.
- Give each child the role reference, complete bounded brief, candidate identity,
  permitted inputs, checks, resource budget, stopping condition and expected
  handoff. Do not assume inherited conversation or access across machines.
- Delegate independent implementation and evidence collection. Prepare review and
  applicable artifact/customer QA alongside coding. Use the
  [bounded review loop](../../../.agents/skills/thistle-build/SKILL.md#bounded-review-loop)
  and [single PR-watch owner](../../../.agents/skills/thistle-hand-off/SKILL.md#pr-watch-ownership);
  preserve an explicitly retained review or watch responsibility on handoff.
- Keep expensive execution within finite host claims. Preserve explicit source-only,
  one-shot and frozen-procedure constraints. Ordinary harmless setup repair follows
  the existing routine-validation allowance rather than a new permission round.
- Resolve demonstrated findings and batch related corrections. Name the settled
  candidate before affected installed checks; build and reuse packages according
  to policy. Preserve earlier candidate identities and failures.
- Prefer a durable simplification over repeated workarounds. Propose reusable
  guidance or an executable guard only for an observed cause, with a bounded
  check and maintenance benefit.

## Return

Provide the coherent diff, exact head/base, completed checks and limits, material
review dispositions, remaining obligations and next owner. Keep the technical PR
summary current, send metadata changes to the PM, and release claims promptly.

## Boundaries

Integrate only when explicitly the named integration owner and authorized to do
so. Otherwise hand back through that owner. Preserve signing and existing gates;
stop the affected step on unavailable authority or exhausted bounds while useful
independent work continues. This role adds no qualification or publication power.
