Installed development receipts now retain the resolved path and digest of the
actually loaded native library before contract execution, including when a later
contract fails. These observations identify the installed build; they do not
archive its binary bytes or substitute the checkout build for that installation.
The macOS CI artifact includes those JSON receipts and contract stdout/stderr on
both success and failure, alongside the source gems and dependency locks.
Core known-answer fixture data is staged outside the checkout before installed
contracts run, with retained byte hashes; fixture reads do not load checkout code.
