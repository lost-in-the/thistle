Static capture and Find do less redundant work on large source trees: the native capture result is moved into its response instead of being serialized into a second copy, facts and links are sorted with keys read once per element, each file is hashed once, repeated call sites no longer allocate a link before deduplication, literal Find skips windows that cannot match while charging the same comparison budget, and named Find looks up identities directly. Captured facts, identities, generations, Find results, ranks and reported work budgets are unchanged.
